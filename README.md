# 영어 단어 시험지 생성기

교재와 Day를 고르면 뜻 쓰기 / 스펠링 쓰기 단어 시험지와 답지를 A4로 만들어 인쇄하는 정적 웹사이트입니다.
서버·DB·빌드 도구 없이 GitHub Pages에서 바로 동작합니다.

- 사이트 주소: https://crexont.github.io/word-test/

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면과 동작 |
| `img/logo.png` | 시험지 왼쪽 위 학원 로고 (같은 이름으로 바꿔 넣으면 교체됨) |
| `data/books.json` | 교재 목록 |
| `data/<교재id>.json` | 교재별 Day·단어 데이터 |

## 교재 추가하기

1. `data/` 폴더에 새 교재 파일을 만듭니다. 예: `data/voca-basic.json`

   ```json
   {
     "title": "기본 영단어",
     "days": [
       { "day": 1, "words": [["abandon", "버리다, 포기하다"], ["ability", "능력"]] },
       { "day": 2, "words": [["benefit", "이익, 혜택"]] }
     ]
   }
   ```

   - `words`의 각 항목은 `["영어 단어", "우리말 뜻"]` 순서입니다.
   - 파일은 UTF-8로 저장하세요.

2. `data/books.json`에 한 줄을 추가합니다. (`id`는 영문·숫자·하이픈 권장)

   ```json
   [
     { "id": "wordmaster-2000", "title": "워드마스터 수능 2000", "short": "수능2000", "file": "data/wordmaster-2000.json", "cover": "data/covers/wordmaster-2000.jpg" },
     { "id": "voca-basic", "title": "기본 영단어", "file": "data/voca-basic.json" }
   ]
   ```

   선택 항목:
   - `"short": "수능2000"` — 시험 제목에 쓸 약칭 (예: "수능2000 Day 1-2"). 없으면 교재 이름 전체를 씁니다.
   - `"cover": "data/covers/voca-basic.jpg"` — 표지 이미지 (이미지는 `data/covers/`에 넣기, 세로 3:4 비율 권장)
   - `"color": "#1d5c45"` — 표지 이미지가 없을 때 자동 표지의 색
   - `"scope": "표제어만"` 또는 `"표제어+파생어"` — 교재 카드 아래에 범위 태그로 표시

3. 변경 사항을 커밋하고 push하면 1~2분 뒤 사이트에 반영됩니다.
   (GitHub 웹에서 파일을 직접 고치고 "Commit changes"를 눌러도 됩니다.)

## 단어 추가·수정하기

해당 교재의 `data/<교재id>.json`에서 Day의 `words` 목록에 `["단어", "뜻"]`을 추가하거나 고치면 됩니다.
새 Day는 `days` 목록에 `{ "day": 번호, "words": [...] }`를 추가합니다.

## 로컬에서 확인하기

`index.html`을 더블클릭하면 데이터 파일을 못 읽으므로 로컬 서버로 여세요.

```bash
python -m http.server 8765
```

브라우저에서 http://localhost:8765 에 접속합니다.

## 참고

- 같은 영어 단어가 여러 Day에 있으면 한 번만 출제 대상에 포함됩니다.
- 마지막 설정(교재, Day, 문항 수, 옵션)은 브라우저에 저장됩니다. 날짜는 항상 오늘로 시작합니다.
- 인쇄할 때 브라우저 인쇄 창에서 용지는 A4, 여백은 "기본값" 또는 "없음", 배율은 100%로 두세요.

## 진도표(구글 시트) 연결

사이트의 **진도표** 탭은 구글 시트를 읽어서 학생별 다음 범위를 보여 주고, 여러 학생의 시험지를 한 번에 인쇄하고, "통과"를 누르면 시트에 오늘 날짜를 적습니다.

### 1. 시트 만들기
첫 번째 탭에 아래처럼 만듭니다. (기존 엑셀을 구글 드라이브에 올려 구글 시트로 열어도 됩니다.)

| 학년 | 교재 | 이름 | 1 | 2 | 3 | 4 | … | 60 | 비고 |
|---|---|---|---|---|---|---|---|---|---|
| 고1 | 수능2000 | 학생 이름 | 11/12 | 11/12 | 11/15 | | | | |

- **학년**(선택): 중3, 고1, 고2 등. 있으면 사이트에서 학년별로 걸러 보고 묶어 보여 줍니다. 병합해도 됩니다.
- **교재**: 사이트의 약칭이나 교재 이름(수능2000 / 수능필수 / 어원편고등 / 보카클리어). 칸을 병합해도 되고, `(Day 50)` 같은 괄호는 무시합니다.
- **Day 칸(1, 2, 3 …)**: 통과한 Day마다 날짜를 적습니다. 첫 빈칸부터 다음 시험 범위가 됩니다. 교재 Day 수를 넘는 칸은 무시합니다.
- 한 번에 볼 Day 수는 사이트에서 정합니다 (기본값 + 학생별로 1~5개). "통과 ✓"를 누르면 그 범위의 Day 칸마다 오늘 날짜가 들어가고, "↶"는 마지막에 같은 날짜로 통과한 Day들을 지웁니다.
- 2 Day 단위 칸(1-2, 3-4 …)으로 만든 시트도 읽을 수 있습니다 (이때는 칸 하나가 한 단위).
- **회독**: 같은 칸에 날짜를 쉼표로 이어 적습니다 (예: `11/18, 2/3` = 2번 통과). 마지막 Day까지 통과하면 자동으로 2회독 Day 1부터 다시 시작하고, 학생 이름 옆에 "2회독"이 붙습니다. 시험지 제목에도 "(2회독)"이 들어갑니다.
- 머리글이 두 줄(위: 교재·이름, 아래: 1-2, 3-4 …)이어도 됩니다. 머리글 위에 제목 줄이 있어도 됩니다.

### 2. Apps Script 붙여 넣기 (처음 한 번)
1. 구글 시트 메뉴 **확장 프로그램 → Apps Script**
2. 기본 코드를 모두 지우고 이 저장소의 `apps-script/Code.gs` 내용을 붙여 넣고 저장(💾)
3. 오른쪽 위 **배포 → 새 배포** → 유형 선택(⚙) **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 권한 승인(내 구글 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용)
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사

### 3. 사이트에 연결
사이트 **진도표** 탭 → "Apps Script 웹 앱 주소"에 붙여 넣고 **연결**.
주소는 그 컴퓨터의 브라우저에만 저장되고 저장소(공개)에는 들어가지 않습니다. 다른 PC에서는 한 번 더 붙여 넣으면 됩니다.

> 웹 앱 주소를 아는 사람은 진도표를 읽고 고칠 수 있으니 주소는 학원 안에서만 공유하세요.
> `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다.

### 4. 관리 기능 (학생 추가·수정·삭제) — 선택
1. Apps Script 편집기 위쪽의 함수 목록에서 **setupAdminKey** 를 고르고 **▶ 실행** (처음엔 권한 승인)
2. 아래 **실행 로그**에 나온 `관리 키: …` 를 복사
3. 사이트 진도표 탭 → **주소 변경** → "관리 키" 칸에 붙여 넣고 **연결**
4. 학생 목록에 **＋ 학생 추가** 버튼과 학생마다 **✎** 버튼이 생깁니다.
   - 추가하면 같은 학년·교재 묶음 맨 아래에 들어가고, 학년·교재 칸은 자동으로 다시 병합됩니다.
   - 학년이나 교재를 바꾸면 통과 기록을 가지고 그 묶음으로 옮겨집니다.
   - 교재 범위 밖 Day 칸은 자동으로 회색이 됩니다.

> 관리 키는 스크립트 속성에만 저장되고 저장소(공개)에는 들어가지 않습니다. 키가 새어 나갔다면 setupAdminKey 를 다시 실행해 새 키로 바꾸세요.
