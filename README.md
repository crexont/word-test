# 영어 단어 시험지 생성기

교재와 Day를 고르면 뜻 쓰기 / 스펠링 쓰기 단어 시험지와 답지를 A4로 만들어 인쇄하는 정적 웹사이트입니다.
서버·DB·빌드 도구 없이 GitHub Pages에서 바로 동작합니다.

- 사이트 주소: https://crexont.github.io/word-test/

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면과 동작 |
| `img/logo.png` | 시험지 왼쪽 위 학원 로고 (같은 이름으로 바꿔 넣으면 교체됨) |
| `img/logo-header.png` | 화면 제목 옆 로고 (logo.png에서 바깥 흰 배경을 뺀 것) |
| `img/favicon.svg`, `img/favicon.png` | 브라우저 탭·북마크 아이콘 (로고를 단순화한 것) |
| `data/books.json` | 교재 목록 |
| `data/<교재id>.json` | 교재별 Day·단어 데이터 |
| `apps-script/Code.gs` | 진도표 구글 시트에 붙여 넣는 Apps Script |
| `docs/superpowers/` | 기능 설계·작업 계획 기록 |

## 교재 추가하기

1. `data/` 폴더에 새 교재 파일을 만듭니다. 예: `data/voca-basic.json`

   ```json
   {
     "title": "기본 영단어",
     "days": [
       { "day": 1, "words": [["abandon", "버리다, 포기하다"], ["ability", "능력"]] },
       { "day": 2, "words": [["benefit", "이익, 혜택"]] }
     ]
   }
   ```

   - `words`의 각 항목은 `["영어 단어", "우리말 뜻"]` 순서입니다.
   - 파일은 UTF-8로 저장하세요.

2. `data/books.json`에 한 줄을 추가합니다. (`id`는 영문·숫자·하이픈 권장)

   ```json
   [
     { "id": "wordmaster-2000", "title": "워드마스터 수능 2000", "short": "수능2000", "file": "data/wordmaster-2000.json", "cover": "data/covers/wordmaster-2000.jpg" },
     { "id": "voca-basic", "title": "기본 영단어", "file": "data/voca-basic.json" }
   ]
   ```

   선택 항목:
   - `"maxDay": 50` — 교재의 마지막 Day (진도표에서 이 Day를 넘는 칸은 회색·무시)
   - `"sheetColor": "#f4b183"` — 진도표 시트에서 이 교재 학생 칸의 색
   - `"short": "수능2000"` — 시험 제목에 쓸 약칭 (예: "수능2000 Day 1-2"). 없으면 교재 이름 전체를 씁니다.
   - `"cover": "data/covers/voca-basic.jpg"` — 표지 이미지 (이미지는 `data/covers/`에 넣기, 세로 3:4 비율 권장)
   - `"color": "#1d5c45"` — 표지 이미지가 없을 때 자동 표지의 색
   - `"scope": "표제어만"` 또는 `"표제어+파생어"` — 교재 카드 아래에 범위 태그로 표시

3. 변경 사항을 커밋하고 push하면 1~2분 뒤 사이트에 반영됩니다.
   (GitHub 웹에서 파일을 직접 고치고 "Commit changes"를 눌러도 됩니다.)

## 단어 추가·수정하기

해당 교재의 `data/<교재id>.json`에서 Day의 `words` 목록에 `["단어", "뜻"]`을 추가하거나 고치면 됩니다.
새 Day는 `days` 목록에 `{ "day": 번호, "words": [...] }`를 추가합니다.

## 로컬에서 확인하기

`index.html`을 더블클릭하면 데이터 파일을 못 읽으므로 로컬 서버로 여세요.

```bash
python -m http.server 8765
```

브라우저에서 http://localhost:8765 에 접속합니다.

진도 계산(회독·다음 범위·재시험)과 칸 값 계산을 고친 뒤에는 http://localhost:8765/?selftest 로 열어 개발자 도구 콘솔에 `selftest: 모두 통과`가 나오는지 확인하세요. 가짜 학생으로만 계산하고 시트에는 쓰지 않습니다.

## 참고

- 같은 영어 단어가 여러 Day에 있으면 한 번만 출제 대상에 포함됩니다.
- 마지막 설정(교재, Day, 문항 수, 옵션)은 브라우저에 저장됩니다. 날짜는 항상 오늘로 시작합니다.
- 인쇄할 때 브라우저 인쇄 창에서 용지는 A4, 여백은 "기본값" 또는 "없음", 배율은 100%로 두세요.
- **양면 인쇄** 스위치를 켜면 시험지 뒷면에 답지(또는 다음 학생 시험지)가 오지 않도록 필요한 곳에 빈 페이지를 넣습니다. 프린터 쪽 양면 설정은 "긴 쪽 넘김"으로 하세요.

## 진도표 (구글 시트)

사이트의 **진도표** 탭은 학원 구글 시트를 읽어 학생별 다음 시험 범위를 보여 주고, 여러 학생 시험지를 한 번에 인쇄하고, 통과·재시험을 시트에 기록합니다.
Apps Script 웹 앱 주소(`app.js`의 `SCRIPT_URL`)와 시트 링크(`DEFAULT_SHEET_DOC`)는 코드에 고정되어 있어 어느 PC에서나 바로 연결됩니다. 학원 안에서만 쓰는 주소이니 밖으로 공유하지 마세요.

### 화면
- **목록 | 시트**: 목록은 학생별 다음 범위·최근 기록·진행률, 시트는 구글 시트를 그대로 보여 줍니다 (시트 모드에서는 오른쪽 미리보기를 숨김). "새 창에서 열기"로 시트를 따로 열 수 있습니다.
- **학년 칩**(전체 / 중3 / 고1 / 고2 …)으로 학년별로 걸러 봅니다.
- 학생마다 이번에 볼 **Day 수(1~5개)** 를 고를 수 있고, 체크한 학생들의 시험지가 이름과 함께 오른쪽에 미리보기로 나옵니다. 인쇄 설정(기본 Day 수, 문항 종류, 배치, 답지 위치, 날짜, 양면)은 왼쪽에 있습니다.
- **🖨 진도표**: 지금 보이는 학년의 진도표를 A4 가로로 인쇄합니다. Day 30개씩 한 장(1–30, 31–60), 통과 칸은 초록(날짜), 2회독 이상은 진초록, 교재 범위 밖은 회색.

### 통과·재시험 기록
- **통과 ✓**: 그 학생의 다음 범위 Day 칸마다 오늘 날짜를 적습니다. **↶** 는 마지막에 같은 날짜로 통과한 Day들을 지웁니다.
- **재시험**: 다음 범위 Day 칸에 `재11/18`처럼 표시합니다 (시트에서 연빨강, 통과 날짜로 세지 않음). 이름 옆에 "재 11/18"이 붙고, 다음에도 같은 범위가 인쇄됩니다. 다시 누르면 표시를 지우고, 나중에 통과하면 재시험 표시는 자동으로 지워지고 날짜가 들어갑니다.
- 통과·재시험은 시트의 **기록** 탭에도 한 줄씩 쌓입니다 (날짜 | 학년 | 교재 | 이름 | 범위 | 점수 | 만점 | 결과).

### 저장 (화면 먼저, 시트는 뒤에서)
- 통과·재시험·↶·학생 추가·수정·삭제를 누르면 **화면이 바로 바뀌고**, 시트 저장은 뒤에서 한 건씩 차례로 처리됩니다 (한 건에 2~3초).
- 위쪽 상태 줄에 `저장 중 N건…` → `저장됨: …` 이 표시됩니다. 여러 명을 연달아 눌러도 됩니다.
- 저장 중에는 ↻ 새로고침이 미뤄지고, 창을 닫거나 새로고침하려 하면 브라우저가 경고합니다. `저장됨`이 뜬 뒤에 닫으세요.
- 추가·수정한 학생은 저장이 끝날 때까지 이름 옆에 "저장 중"이 붙고 버튼이 잠깁니다.
- 저장이 실패하면 빨간 글씨로 무엇이 실패했는지 알려 주고, 남은 저장은 취소한 뒤 화면을 시트의 실제 상태로 되돌립니다. 필요하면 다시 누르세요.

### 시트 모양
| 학년 | 교재 | 이름 | 1 | 2 | 3 | … | 60 | 비고 |
|---|---|---|---|---|---|---|---|---|
| 고1 | 수능2000 | 학생 이름 | 11/12 | 11/12 | 11/15 | | | |

- **학년**: 중3, 고1, 고2 등. **교재**: 약칭이나 교재 이름(수능2000 / 수능필수 / 어원편고등 / 보카클리어). 학년·교재 칸은 묶음별로 병합됩니다.
- **Day 칸**: 통과한 날짜. 첫 빈칸부터 다음 시험 범위가 됩니다.
- **회독**: 같은 칸에 날짜를 쉼표로 이어 적습니다 (`11/18, 2/3` = 2번 통과). 마지막 Day까지 통과하면 2회독 Day 1부터 다시 시작하고, 이름 옆과 시험지 제목에 "2회독"이 붙습니다.
- 시트에서 직접 날짜를 적어도 됩니다. 사이트에서 ↻ 새로고침하면 반영됩니다.
- 표 아래(마지막 학생 줄 아래)에 적은 메모와, 시트에서 직접 만든 조건부 서식은 사이트가 건드리지 않습니다. 단, 표 안에서 이름 칸이 빈 줄은 학생 추가·수정·삭제 때 정리되어 사라집니다.

### 관리 기능 (학생 추가·수정·삭제)
관리 키는 공개 저장소에 넣지 않고 **PC마다 한 번** 입력합니다.
1. 사이트 진도표 탭 오른쪽 위 **관리 키** 칸에 키를 붙여 넣고 **저장** (그 PC 브라우저에만 저장됨)
2. 학생 목록에 **＋ 학생 추가** 와 학생마다 **✎** 버튼이 생깁니다.
   - 추가하면 같은 학년·교재 묶음 맨 아래에 들어가고, 학년·교재 칸은 자동으로 다시 병합됩니다.
   - 학년이나 교재를 바꾸면 통과 기록을 가지고 그 묶음으로 옮겨집니다.
   - 교재별 칸 색(`books.json`의 `sheetColor`), 범위 밖 회색, 5 Day 구분선, 고정 줄·열이 자동으로 정리됩니다.

새 키 만들기 (키가 새어 나갔을 때): Apps Script 편집기에서 **setupAdminKey** 를 골라 **▶ 실행** → 실행 로그의 `관리 키: …` 를 각 PC의 관리 키 칸에 다시 저장. 이전 키는 바로 막힙니다.

### Apps Script 고친 뒤 배포
1. 구글 시트 메뉴 **확장 프로그램 → Apps Script** 에 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장(💾)
2. **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** (주소가 바뀌지 않음)
3. 배포 직후 1~2분은 "알 수 없는 요청"이 날 수 있습니다. 잠시 뒤 새로고침하세요.
4. 제대로 배포됐는지는 `Code.gs` 맨 위의 `VERSION`(지금 14)으로 확인합니다. 사이트가 이 값을 보고 기능을 맞춥니다.

처음부터 새 시트에 설치할 때는 **배포 → 새 배포 → 웹 앱**(실행 사용자: 나, 액세스: 모든 사용자)로 배포하고, 나온 웹 앱 주소를 `app.js`의 `SCRIPT_URL`에 넣습니다.

> 학생 이름이 들어간 파일(엑셀 진도표 등)은 이 저장소(공개)에 올리지 마세요.
